# 数学教学工作台

左侧可以切换周教学计划、座位表、作业登记、学生档案、考试分析、进度记录、反馈及逐题切图。

## 打开工作台

Windows 下双击 `启动工作台.cmd`，或运行 `node preview.cjs` 后打开 `http://127.0.0.1:8768/`。预览只监听本机地址，核心功能可以断网使用。也可直接打开 `index.html`。浏览器和打开地址变化后，请用对应备份恢复数据。

## 周教学计划

- 「总览」按周显示三个走班，每天安排上午 5 节和下午 4 节。点击课格可排课或编辑。
- 选择 IG1、IGB 或 IG3，可按天查看该班课次、填写每节课的教学内容和当天的作业。
- 旧计划中缺少具体节次或教学班的记录保留在待安排区域，可按实际课表逐项补齐。

## 进度记录

- 「家校沟通」默认显示当天。选择未沟通、家长主动沟通或我主动沟通，可按日期补录、填写备注或查看历史。
- 在「每周提问」选择教学周，填写学生本周累计的提问次数。每周从周一到周日。
- 学生档案中的「沟通与提问记录」汇总所选日期内的沟通次数、备注和逐周提问数。默认从本学期起始月开始，可调整日期或查看全部记录。
- 两张表随学生档案保存在当前浏览器，包含在右上角的「备份数据」中。

## 备份与恢复

- 学生档案、总分和评语用右上角的「备份数据」和「恢复备份」。
- 答题卡、逐题得分和切图用「逐题分析与切图」里的备份入口，格式为 ZIP。
- 座位、章节作业和周计划用任一教学页里的「导出备份」和「导入备份」。旧「数学走班教学工作台」导出的 JSON 可直接导入。
- 「同步学生档案名单」用于补充教学模块里尚无的学生。已有教学记录继续使用原有学生编号。
- 调出学生可在学生档案选择「归档学生」。归档后从当前班级名单和统计中隐去，历史档案仍可通过「显示已归档学生」查看或恢复。
- 学生档案中的逐题成绩和答题卡按考试折叠。展开该场考试可查看逐题成绩、整卷和切片，也可在反馈区选用已整理的试卷分析。

保留整个项目目录，HTML、样式、脚本和本机启动文件需要放在一起。学生数据和备份保存在本机，请勿提交到 GitHub。
